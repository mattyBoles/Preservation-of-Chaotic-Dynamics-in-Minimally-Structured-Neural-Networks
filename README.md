**<u>Preservation of Chaotic Dynamics in Minimally Structured Neural Networks**</u>

The aim of this project is to investigate the ability of minimally structured multi-layer perceptrons to learn the dynamics of a chaotic dynamical system from prediction error alone, and to identify and diagnose shortcomings and failure modes. Using the canonical test bed of Lorenz-63, we investigate the choice of optimiser, network width and activation function. We employ Lyapunov spectra and singular value decomposition of the discretised flow map, to evaluate a model's success. We find that a curvature-aware optimiser is more effective at converging at a low-MSE minimum, consistent with the ill-conditioned loss landscape with highly coupled parameters. Analysis of activation functions highlights a structural limitation of ReLU caused by the piecewise-constant derivative. We identify a failure mode of tanh, in which singular value decomposition shows sharp increases in contraction, unrepresentative of the true system. Softplus avoids this failure mode, and captures the dynamics more consistently, especially in narrow systems. By testing a range of widths on Lorenz-63, we find increased width provides more consistently accurate dynamics. However, investigating the generalisation to Lorenz-96 instead shows a minimum viable width, for which higher widths show no additional benefit. These results demonstrate that small multi-layer perceptrons can reproduce the important properties of chaotic systems, but their success is highly variable and performance cannot be established by prediction error alone.
